# TrailBridge

Your Garmin, in Finder.

TrailBridge is a macOS menu bar app for browsing supported Garmin USB/MTP devices in Finder. Copy activities to your Mac, send courses to your Garmin, and preview FIT, GPX, and TCX routes with Quick Look.

## Download

Download the DMG from [Releases](https://github.com/n0rt0nthec4t/TrailBridge-downloads/releases). The first signed release is being prepared; if no release is listed, there is no download available yet.

Each release includes user-facing release notes and a SHA-256 checksum. The app requires **macOS 15 or later**. Testing currently focuses on the **Garmin Edge 1040**; other Garmin MTP devices still need testing.

## Install and connect

1. Download and open `TrailBridge-<version>.dmg`.
2. Drag **TrailBridge** into **Applications**, then open it.
3. If prompted, allow its extensions in System Settings.
4. Connect your Garmin using a USB data cable and select its file-transfer mode if prompted.
5. In Finder, select **TrailBridge** under Locations and open your Garmin's folder.

TrailBridge runs in the menu bar. Right-click or Option-click its icon for connection details and Finder refresh actions.

## Useful to know

- Quick Look route map backgrounds need an internet connection. Route thumbnails work offline.
- Deleting files or folders in Finder permanently removes them from the Garmin.
- Close other apps that access the Garmin if it cannot connect.
